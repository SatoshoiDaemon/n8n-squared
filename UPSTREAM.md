# Origem do código

Este arquivo registra somente a proveniência histórica do código preservado no repositório. As versões e releases do produto Squared são independentes dessa origem; o runtime próprio atual começa em `0.1.0`.

- Projeto original: [n8n-io/n8n](https://github.com/n8n-io/n8n)
- Tag utilizada: `n8n@2.42.7`
- Commit original: `92e4ff858a6ec0dc3ce3995d8696861575698bd0`
- Licenças originais: [LICENSE.md](LICENSE.md) e [LICENSE_EE.md](LICENSE_EE.md)

O primeiro commit do n8n-squared contém um snapshot do código dessa tag, após a remoção de material de promoção, automações internas e arquivos de distribuição por imagem. Ele não possui os commits anteriores do n8n como ancestrais Git.

O remote `upstream` não é necessário nem configurado por padrão. A árvore `packages/` é material de referência, não uma integração de releases. Se for preciso consultar o repositório original, adicione o remote localmente e compare apenas o código que tenha sido escolhido para portar. Preserve os avisos legais; não sincronize automaticamente versões ou ciclos de release do Squared com o n8n.
